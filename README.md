# For My Janu ♡ — Personal Romantic Website

A mobile-first, intimate single-page website crafted with **pure HTML and CSS**.

## Files
- `index.html` — The main single-page website containing all 8 sections and messages.
- `style.css` — Romantic dark purple & midnight styling, glassmorphism cards, glowing clock, glowing particles, and smooth animations.

## How to host on GitHub Pages (Takes 1-2 minutes):

1. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Name it (for example: `for-wifey` or `for-janu`).
   - Set it to **Public**.
   - Click **Create repository**.

2. **Upload files**:
   - Click **Upload files**.
   - Drag and drop `index.html` and `style.css` directly into the repository.
   - Click **Commit changes**.

3. **Enable GitHub Pages**:
   - Go to your repo's **Settings** tab (gear icon at top).
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment** > **Branch**:
     - Change from `None` to `main` (or `master`).
     - Leave the folder as `/(root)`.
     - Click **Save**.

4. **Send link on WhatsApp**:
   - In about 30–60 seconds, your site will be live at:
     `https://<your-username>.github.io/<repo-name>/`
   - WhatsApp will automatically show the romantic preview title and description:
     *"For My Janu ♡ | A little secret for wifey"*
